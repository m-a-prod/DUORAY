Arch, CachyOS, Manjaro

Подключите репозиторий один раз, дальше DUORAY обновляется вместе с системой.

curl -fsSL https://duoray.pro/arch/duoray.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key 13F077054DB026DC11D58144254C5F497BDAC7B9
printf '\n[duoray]\nServer = https://duoray.pro/arch/$arch\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Sy duoray
